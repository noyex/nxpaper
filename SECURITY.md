# Security

## Reporting a vulnerability

Please don't open a public issue. Report it privately through
[GitHub's security advisories](https://github.com/noyex/nxpaper/security/advisories/new).
You'll get an answer within a few days.

## What nxpaper promises

- It makes no network requests.
- It only reads its own bundled wallpapers.

A wallpaper that loads anything from the network breaks both, and is a vulnerability.
